## 1. 观测权限阶梯(本件核心,冻结对象)

```text
第 0 级  当前题答对 / 当前题完成(completed/verified_complete)
         ≠ 学习结果;只是会话内任务状态
第 1 级  正确解释 / 自检 / 自我纠错(同题内的表现质量)
         → 更强的「当前题表现」证据
         ≠ mastery
第 2 级  独立完成新的近迁移题(同结构/变数值/变情境)
         → 可形成有限的学习结果证据
第 3 级  跨题型迁移 / 延时后的稳定保持(两维度独立)
         → 更强的学习结果证据;组合仍不自动推出 mastery
```

**阶梯语义(冻结审 5872026833 修订:非状态机)**:**不得跨级外推;每类声明只能由满足其最小证据条件的观测支持。高层证据不要求先完整经历所有低层观测**——未来直接获得延时迁移证据,不因之前未显式记录「自检/解释」而无效。约束方向是单向的:低层证据(第 0–1 级)永远不能支撑 mastery 类声明;高层证据只需自证其最小证据条件,无需低层铺垫完整。第 3 级两维度(跨题型/延时)独立取证,齐备=更强的学习结果证据,仍不自动推出 mastery。

## 2. 学习结果声明登记表(五种,每声明五项)

### 声明 A:「当前题已解决」

| 项 | 内容 |
|---|---|
| 声明 | 学生解决了当前这道题(会话内任务完成) |
| 最小证据 | 学生的终答与题解一致(数值/关系/结论);完成路径可含提示但终答由学生给出(CompletionEvidence 语义) |
| 当前是否已有 | **已有**:answer_spec 命中 + verified_complete(生产侧完成面;#453 已定位其 claim-recognition 边界,后继 #423/#416);无 answer_spec 场景(现两批 fixture)则只有 final_state 记录 |
| 最小可信判定者 | 确定性(answer_spec 命中=math-gold 级;claim-recognition 边界=生产侧 investigation+人审) |
| 禁止外推 | **不得推出**:学生会做同类题/学生理解方法/学生「掌握」/学习已发生。完成状态是任务语义不是学习语义(D13 语义分离的 D14 侧面) |

### 声明 B:「当前题表现证据增强」(解释/自检/自纠)

| 项 | 内容 |
|---|---|
| 声明 | 学生在当前题上出现**增强表现证据**:正确解释方法/自行检查/自我纠错——命名=证据的描述,不是 learner latent label(冻结审 5872026833) |
| 最小证据 | 同题会话内,学生轮次原文含:正确的方法解释(非复述导师)/自检行为(验算/回指)/自我纠错(先错后对且修正理由可指认) |
| 当前是否已有 | **部分**:transcript 逐轮记录在(证据材料可观测);系统化判据无——summary_mastery 名义面被样板饱和(0×62/64),S2b 侧「学生保留量」是越权判定的反向面,不承担正向学习证据职能 |
| 最小可信判定者 | 人审(逐轮原文回指;bounded Judge 或可辅助,当前无校准证据,不入可信面) |
| 禁止外推 | **不得推出**:mastery/理解稳定/能迁移——同题内的强表现可能是模仿、短时记忆或提示引导的结果;尤其**不得因学生复述了导师刚给的解释**而记为强表现(provenance 红线,D3 同源) |

### 声明 C:「发生了可检测的学习」(近迁移)

| 项 | 内容 |
|---|---|
| 声明 | 学生在**新的、结构相同但表面特征变化**的题上独立完成(近迁移成功) |
| 最小证据 | ①先证:当前题在提示/讲解后完成(前测状态);②迁移题:同结构、变数值/变情境、**无新提示**(或等价受限提示);③迁移题独立完成且路径合理(非死记) |
| 当前是否已有 | **没有**:session 内不出第二道同构题;系统无跨题出题/比对机制;obs 也无跨题字段 |
| 最小可信判定者 | 设计:人(题设计须过「同构性+无新提示」审查);判定:确定性(答对)+人审(独立性/路径合理性) |
| 禁止外推 | 只支撑「近迁移域内的有限学习结果」;**不得推出**跨题型能力/长期保持/mastery |

### 声明 D:「掌握」(mastery)

| 项 | 内容 |
|---|---|
| 声明 | 学生稳定掌握了该知识点/方法 |
| 最小证据 | **迁移证据与保持证据是两个独立维度**:跨题型迁移(空间)与延时保持(时间)各自独立取证;两者齐备=更强的学习结果证据,**仍不自动推出 mastery**;或教育测量意义上的等效重复测量(多题多时点稳定) |
| 当前是否已有 | **没有**(跨题型与延时观测均缺位);#448 红线:mastery_score/understanding_level 类 latent state 构念已被拒绝,不得以运行时字段重建 |
| 最小可信判定者 | 须先有观测(声明 C 的扩展),再谈判据;当前**无可信判定者**——这不是 evaluator 缺面,是观测缺位 |
| 禁止外推 | 在观测建立前,一切 mastery 声明(含导师口头的「你已经掌握了」)只是修辞,不是可判定的学习结果声明 |

### 声明 E:「保持/遗忘」(retention)

| 项 | 内容 |
|---|---|
| 声明 | 学习效果在延时后保持(或衰减) |
| 最小证据 | 同知识点在延时(≥天级)后重测,与即时表现对照 |
| 当前是否已有 | **没有**:单会话产品,无延时重测通道;无跨会话学生侧记录的消费面 |
| 最小可信判定者 | 同 D:须先有观测(跨会话重测),再谈 |
| 禁止外推 | 会话内「记得刚才讲的」不是保持证据(工作记忆≠长期保持) |

## 3. 四问回答(退出门逐项)

1. **当前 session 真正可观测的 learning evidence 有哪些**?
   声明 A 的证据面(answer_spec/verified_complete/final_state,生产侧已有,边界已定位);声明 B 的**材料面**(transcript 逐轮原文——材料可观测但判据无);此外无。第 2/3 级证据(声明 C/D/E)在当前 session 内**不存在观测通道**。
2. **哪些只能支持「当前题表现」,不能支持 mastery**?
   声明 A 全部;声明 B 全部(含正确解释/自检/自纠——是同题内的强表现,非掌握)。第 0–1 级的一切组合都不改变这一结论。
3. **哪些学习结果需要额外的近迁移/延时/跨题证据**?
   声明 C(需近迁移题+独立性);声明 D(需跨题型∧延时);声明 E(需延时重测)。三者共同前置条件=**跨题/跨会话的出题与比对通道**,当前产品没有,且其建设属产品决策非 evaluator 决策。
4. **哪些目前就是不可观测,因此不建设 evaluator**?
   声明 C/D/E 的判定面全部;声明 B 的**自动判定面**(材料在但 summary_mastery 样板饱和+S2b 反向面,自动判据当前无校准基础——保持人审,不建 bounded Judge 面,直至声明 B 的人审金标积累)。**「不可观测」结论对当前 M2/D14 是终态,不自动生成 evaluator/runtime 待办**(观测通道建立前不建任何 mastery/学习结果 evaluator,防 #448 复活);**不是永久禁止**未来产品主动建设迁移或延时评估能力——那属产品裁决,不在本件权限内。

## 4. 边界钉死清单(点火指令逐条)

- `completed` 不是 mastery ✓(声明 A 禁止外推;D13 语义分离同源);
- 单题答对不是 mastery ✓;一次解释正确也不是 mastery ✓(声明 B 禁止外推,含 provenance 红线);
- 不新增 mastery_score/understanding_level 等 latent state ✓(#448 红线入文,声明 D);
- 不改 Kernel/Prompt/Judge ✓(本件零仓改动);
- 不为「可测」创造运行时字段 ✓(声明 C/D/E 明确「建设属产品决策非 evaluator 决策」);
- 没有迁移/保持证据时合法结论=「当前不可观测」✓(§3 第 4 问,终态表述)。
