### 5.1 代价对照(客观维度)

| 维度 | 路径 A:护栏重生成 | 路径 B:解析脱敏 |
|---|---|---|
| 落点 | 扩 `kernel._guard_check` 加一条规则 + 复用现成 `_regenerate`/`_contextual_fallback` | 新增回复后处理函数(在 `_guard_output` 之后) |
| 额外模型调用 | 每条命中 +1 次 tutor 调用(本轮去重强命中 7 条;实际按命中轮次计) | 0 |
| 失败模式 | 重生成仍违规 → 兜底句**整条替换**教师回复 + `session.stuck=True`(会改 R6 `finish` 的确定性模板通路) | 机械删词后**全部** 7/7 条致损:方法名类 2 条留孤儿动词,数字类 5 条留空洞/语义断裂 |
| 文本完整性 | 保留原轮内容(重写),不产生破损句 | A 类命中**必然**破损(如「你用假设法很聪明」→「你用很聪明」);数字类删后留空洞 |
| 维护面 | 需方法名词表 + 检测规则 + 重写率/失败率实测 | 需同一份词表;无需模型侧规则 |
| 与弧线的冲突 | 弧线要求"他讲完你再点名方法" → 检测须带"学生是否已说出"状态(现 `student_evidence` 已有该信号) | 同上,且脱敏会把**合规的点名**也一起删掉 |

### 5.2 本轮数据能定/不能定的

* 能定:方法名代喂在 11 场景里只出现在**总结句**(两臂皆有);答案数字代喂真实存在且两臂相同(鸡兔同笼第 3 轮教师先说「需要换5只兔」,学生尚未说出)。
* 不能定:两路径的**实际拦截成功率与代价**需要各自实现一版后重跑同一 88 份口径才能测;本轮只提供**语料与机械可拦性**,因此不下路径结论。
