## 1. 业界方案(四条线)

| 线 | 代表工作 | 对我们要点 |
|---|---|---|
| 护栏 / 安全性 | [Evaluating Answer Leakage Robustness of LLM Tutors against Adversarial Student Attacks (ACL 2026)](https://arxiv.org/abs/2604.18660) | 教学微调模型泄露率**最高**(TutorRL-7B / MathDial-SFT 70-83%);**说服型攻击(74%)优于硬攻击(47%)**,"故意答错钓鱼"是教育特有招;**大模型不更稳**(Qwen-72B 80% > 32B 46%);两种轻量防御把 46% 压到 2-4%:①回复前输出 `reason` 规划字段 ②tutor→judge→refiner;作者结论:**泄露多半是 prompt 协议问题,不是基座能力问题** |
| 多模态辅导评测 | [MMTutorBench (2025-10)](https://ar5iv.labs.arxiv.org/html/2510.23477) | 人类专家 5.85/6,最强模型 4.77,开源最强 3.45 → 全行业离人类都远;**最难一维是 Solution Scope Control(别给全解)**,GPT-4o Study Mode 仅 0.11;**OCR 管道掉分**(4.77→4.16)故图像须直传;rubric+LLM-judge 与人类相关 r=0.725、双 judge >0.98 |

| 经典 ITS | [Andes: Fading and Deepening](https://experts.azregents.edu/en/publications/fading-and-deepening-the-next-steps-for-andes-and-other-model-tra);[自我解释实证(Renkl 1997)](https://summit.sfu.ca/_flysystem/fedora/2022-08/input_data/20986/etd21092.pdf) | **步骤级模型 + 脚手架渐隐**是标配;**不显式提示,学生大多不会自我解释** |

## 4. 马尾辫自审(**§4-§6 为本文档核心**)

### 4.1 三条"现成机制核查"(改变了结论)

- **核查 1(重要)**:`TUTOR_TURN_SCHEMA` 现有字段为 `reply` / `ready_to_confirm` /
  `cited_numbers`,其中 `cited_numbers` 是**模型自报**字段;而夜评影子数据实测其**虚报**
  (`cited=[38,45,120]` vs `extracted=[]`),退役条件已定。→ **M1 的 `reason` 必须定性为
  "规划装置"而非"验证装置"**:只用于改变生成(自我承诺),**不得进入任何判定逻辑**,
  否则即重犯 `cited_numbers` 的错。
- **核查 2(省一天工)**:grammar 强制下 **字段声明顺序 = 生成顺序**。`reason` 若排在
  `reply` 之后,等于没加(CoT 效应来自"先承诺策略、再回答")。→ M1 缩为**首位插入**这一条硬细节。
- **核查 3**:我们**已有逐轮机制**——`guard_events` 是逐轮事件,#143 的 pre-registration 已定义
  逐轮 judge 字段。→ **M2 从"造评测"缩为"并口径",零新造。**

### 4.2 逐条裁决

| 编号 | 裁决 | 理由 |
|---|---|---|
| M1 | ✅ 采纳(缩窄) | 论文实证 + 已有 schema;缩窄为"首位字段 + **不得用于判定**" |
| M2 | ✅ 采纳(大幅缩窄) | delete-first:先复用已有逐轮字段,不新建评测框架 |
| M3 | ✅ 采纳(不新增工作) | 就是 #107,本清单只**调优先级**(ITS 标配 → M3 首位) |
| M4 | ⚠️ 降级 M3 + 砍到 2 类攻击 | YAGNI:实测泄露(鸡兔同笼第 3 轮"需要换5只兔")**不需要对抗学生即可复现** → 先修普通路径;对抗评测是新风险面 |
| M5 | ⚠️ 降级 M3+ | 结构性改造,M2 收尾期不值当;且 M2 已能定位问题 |
| M6 | ❌ 砍掉(YAGNI) | 论文自承盲区;我们实测问题是**过度宽松**(判停过早/虚报掌握)而非过度保守,无实测驱动 |
| M7 掌握度建模 | ❌ 砍掉 | 需纵向多课次数据,当前是单课单题剧本 → 触发条件未到 |
| M8 长对话退化防护 | ❌ 合并 | 症状(9 轮复读循环)根因是确定性兜底模板,已被 **#112** 覆盖 → 转为 #112 验收项(轮数对照) |
