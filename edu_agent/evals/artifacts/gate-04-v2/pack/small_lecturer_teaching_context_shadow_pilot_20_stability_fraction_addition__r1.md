# small_lecturer_teaching_context_shadow_pilot_20_stability_fraction_addition__r1

## 题目
计算四分之三加八分之一，并说明为什么要这样算。

## Transcript A
导师: 你好同学,这道题你的答案是什么呀?讲讲你的思路吧!
学生: 我能不能直接把分子和分母分别相加？
导师: 先回到你刚说的「我能不能直接把分子和分母分别相加？」——你能从题目里再确认一个已知条件吗?
学生: 直接算成十二分之四好像不对，因为每一份的大小不同。
导师: 你刚才说‘每一份的大小不同’，这说明你已经发现不能直接加分子和分母了，那接下来我们该怎么做才能让它们变成相同大小的份呢？
学生: 我把四分之三化成八分之六，再加八分之一。
导师: 你刚才说把四分之三化成八分之六再加八分之一，这一步很聪明，因为这样就把两个分数变成了相同大小的份，能直接相加了，对吗？
导师: 你用‘通分’的方法把四分之三化成八分之六，再加八分之一，这一步很聪明，因为这样两个分数就变成了相同大小的份，能直接相加了。仍需注意：加完后要检查结果是否能约分，比如八分之七是否可以简化。
