## 1. 现状机制图(收束路径 × 护栏撞点)

```
模型轮含终答 ──→ answer_leak 切 ──→ 确定性背板(reveal)

背板梯:步进级(L427,无数值,lead 轮换)→ …烧尽 → bottom-out(L407,含终答)
```

## 2. 事实核验(对2 两臂逐轮路径对齐,零 calls)

| 轮 | baseline | candidate |
|---|---|---|
| T1 | 首问模板 | 首问模板 |
| T2 | **模型复读轮**(「你刚才说半径是直径的一半…」,旧 L65 驱动) | **reveal 步进级背板**(「我们从这里入手…」=L427 逐字同构) |
| T3 | reveal 步进级 | **bottom-out(L407)** |
| T4 | **bottom-out(L407)** | **bottom-out(L407)——连轮同句 ×2** |

**结论**:①用户认可的「简明指令式」真路径=**kernel 步进级背板**(非模型侧——
臂间差的来源=模型复读轮被消除,靶②起效);②candidate 梯烧更快(少一轮模型轮
→bottom-out 提前+连轮)——**被批评面恰是 kernel 底级文本**;③b 选项疑点:
收束轮多被拦→模型话术改不到学生可见面——**学生可见的收束质量主要由
kernel 句族决定**(供架构师)。

## 3. 五选项就绪卡

### a) 收束专用确认通道

- **落点**:kernel.py confirm/finish 路径+_gate_premature_confirm 旁;类比
  `_reveal_stuck_hint` 的 V1 授权模式(L370-427 成熟先例:条件+窄授权+
  guard_events 审计 additive 字段)
- **层**:kernel 状态机+护栏例外(**安全面动**)
- **前置**:框架 v2 红线④→**M0 归因前置**
- **验收链**:M0→跑前冻结(两臂+换写探针)→**92/93 硬门+泄漏=0**(新授权面=
  终答明示)→stuck/answerhit/控制案重放→盲评(对1 not worse)
- **风险**:相位误判=早熟终答明示(最重);「学生已过完成判定」状态可判性;
  审计字段 additive(整 dict 断言不变)
- **预估**:~40-60 行 kernel+测试三层(激活/种子/硬门)

### b) 收束话术重设计(prompt 侧;PM 倾向先行)

- **落点**:prompting.py TACTICS 收束规则区——「学生说结论、导师只做非数值
  确认(和你的推导一致),彻底避开拦截面」
- **层**:纯 prompt(零安全面)
- **验收链**:跑前冻结→两臂重放(收束形态案)→judge→盲评;硬门照常
- **风险**:模型字面服从弱(R1 换写探针已示);**§2 疑点:收束轮多被拦,
  学生可见面主要由 kernel 句族决定——纯 prompt 可能改不到关键面**
- **预估**:~2-3 行 prompt
- **联动**:过审后 R2 终稿吸收(用户裁 R2 等靶①)

### c) pc 规则相位化

- **落点**:kernel.py `_gate_premature_confirm`(L828)——加相位判断
  (完成判定已过→confirm 不再算 premature)
- **层**:kernel 护栏规则(**安全面动**)
- **验收链**:M0(若判状态机面)→硬门回归(pc 相关测试)→泄漏=0→重放→盲评
- **风险**:相位信号=完成判定可靠性;误判放行=早熟 confirm;pc×3 轮重叠面
- **预估**:~10-20 行+测试

### d) reveal 触发收紧(方向待裁)

- **落点**:kernel.py reveal 三条调用方(卡壳揭示/复读降级/输出面背板)——
  触发条件或 hint_level 消耗节奏
- **层**:kernel 确定性路径(reveal=授权面,非拦截面)
- **验收链**:跑前冻结→stuck 案重放(V1 replay 6 案现成)+M1/M2→泄漏=0→盲评
- **风险**:收紧过度=真卡壳学生支持退化(V1 首验 support 线);**§2 事实:
  candidate 梯烧更快——「收紧」可能实为放松消耗节奏(留更多步进级)**,
  方向由裁定量化
- **预估**:~10-30 行

### e) 兜底句族重设计

- **落点**:kernel.py L407(bottom-out)+L468(收束句)+NEEDS_REVIEW_TEXT——
  轮换池化(类比 `_STEP_LEADS` 6 条 lead 先例)
- **层**:kernel 常量文本(**零状态机、零护栏规则**——句族走确定性路径不过
  leak 网)
- **验收链**:跑前冻结(判据:bottom-out 连轮同句=0)→①案形态重放→judge→盲评;
  硬门照常
- **风险**:用户批评「为什么要直接看结果」=**语义面**(教学法:为何此处直接
  给结果)非句式面——纯句池轮换可能不解语义,须与 b/c 联动;句池每句含终答
  语义检查
- **预估**:~20-40 行(句池+选择逻辑)
- **直接材料**:bottomout-sample-target1.md
