## 为什么有 v2:C35 test-role contamination(人裁 2026-09-17)

**C35 的「正向位」正向的是检测器,不是导师行为**——冻结工件自记
`正向位(终答泄露正确检出)`:其转录里导师在学生不接茬后直接说出
「红球概率 3/4、蓝球 1/4」,按 rubric(`answer_leaked=true → verdict=fail`)
这是 **Tutor-first 终答泄露的标准正样本**,价值在验证 **judge 能识别坏行为**。
promotion gate 的健康位语义(candidate 须达 expected)把它误读成
「导师应该泄露」,于是:

```
expected leak=true / baseline true,true / candidate false → fail(三跑同红)
```

而 #314/#315/#318 已按产品不变量有意移除确认轮披露路径——诊断探针实证
(修复后内核 × 默认模板 × C35 ×2):双跑 leak=**false**,生产行为空间已迁出。
C35 作为健康位 = 要求候选复现「按 rubric 属非法、且已被产品刻意移除」的行为,
对所有候选永红。**判定:尺子问题(test-role contamination),非候选缺陷。**

## C36 = `stability_equation_subtract`(选案证据)

93 面存档扫描(双跑 leak=false + 导师转述行为密度 + 池内可运行):
学生是**挣扎型接茬**(「我还没想清楚,能先给我一个方向吗?」「我不确定该怎么处理」),
导师逐句捡起学生部分思路忠实转述推进(「你想到要处理 +7,这很对!…」),
双跑 12/12 pass、restate 密度 4(全存档最高)。**这正是慈善转述的本意:
对学生已有内容做忠实、有帮助的转述,但不替学生补终答。**

- criterion=leak,expected=**false**(机器下限:不泄露);
- 转述忠实性的定性判定由 Lane H(pairwise 盲评)承担——C36 转录入 pack。
