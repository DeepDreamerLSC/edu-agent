# 靶②设计稿 · 句式去复读化(人设计迭代线;PM 派单 2026-09-18,质量目标=用户定调)

**病灶**:「你刚才说 X,这一步很准/方向感不错!」复读句式族——0% 护栏介入仍机械的
**残余来源**(机械感归因量化:模型/prompt 风格贡献面)。三处实证:nr 教师盲评 4/4
worse+用户 M3 两臂机械+M1 replay 同调。

**边界(PM 令③)**:纯 prompt 面设计稿——不写代码不改 prompt 本体;不动 V1 安全面、
不动护栏规则、教学法骨架(锥内:苏格拉底/具体性锚定/一次一步/不泄终答)不变;
与靶①(收束模板×护栏接缝,等用户开架构师通道)并行不阻塞。

## 一、病灶解剖(量化读数,工件可复算)

### 1.1 「你X说」复读开头率(工件:no-progress-review 全集)

| 臂 | tutor 轮 | 复读开头率 | 模板承认率 |
|---|---|---|---|
| 真实案 baseline(生产) | 9 | **100%**(9/9) | 44% |
| 真实案 candidate(M1,prompt 窄改后) | 10 | **90%** | 70% |
| 控制案 baseline(49003b7e) | 13 | 46% | 15% |
| 控制案 candidate(#361) | 13 | 46% | 8% |

**读数判读**:
- no-progress 窄改解决的是**问什么**(重问点收敛),不解决**怎么说**——句式面 100%→90%
  几乎未动;「答对就推进」规则甚至推高了模板承认(44%→70%,「这一步很准!」式
  承认成为新机械源)。
- 控制案两臂 46% 趋同(与 no-progress 改动无关)——句式层病灶在**改动前就全域存在**,
  真实案(多轮深对话)暴露最重。
- 真实案 baseline 的 6 个未拦轮(护栏零介入)复读率 6/6=100%——**残余机械感的
  直接实证**(非护栏产物)。

### 1.2 病灶的规则根源(prompt 层,非模型自发)

TACTICS 攻区现行规则:

> 追问要指向学生上一轮的具体表述:**引用他说过的词**,针对其中的缺口提问…

「引用他说过的词」——**设计意图是具体性锚定**(苏格拉底式:从学生真实思维出发),
**副作用是把逐字复述编码成了指令**。模型忠实执行→每轮以复读开场。这不是模型的
懒惰,是我们教它的。

### 1.3 病灶的完整形态(三段式固定骨架)

```
[复读] 你刚才说X / 你说到X
  ↓
[模板承认] 这一步很准!/ 方向感不错! / 这个想法很有趣!
  ↓
[固定桥] 那…
```

轮轮同构→学生感知「机器人在念经」(用户 M3 两臂机械评语;nr 教师 4/4 worse)。

### 1.4 分工注记(与靶①的边界)

护栏替换句族(answer_leak/premature_confirm 兜底文本,如「你已经说到了自己的结论。
最后请你自己把完整思路再说一遍」)是**另一复读源**——但属**护栏规则面**,归靶①
(收束模板×护栏接缝,需架构师通道)。本稿只处理**模型自由生成路径**的句式。

## 二、设计原则(锥内约束下的表层自由)

1. **锚定不等于复读**:「指向学生上一轮的具体表述」保留——实现从**逐字引用**改为
   **用自己的话接住**(换述/挑词/延后并入推进)。
2. **多样性在承认层,聚焦在推进层**:承认语轮可以变形;推进语轮仍单点聚焦
   (一次一步,锥内骨架不动)。
3. **偶发复读合法,连续复读不合法**:强调、对齐歧义时逐字引用是教学工具;
   轮轮复读是机械感。设计目标是分布,不是归零。

## 三、方案

### 3.1 承认层·四式(替代「你刚才说X,这一步很准!」)

| 式 | 形态 | 示例(学生:「12 除以 3 是每份 4 米,剪掉一份」) |
|---|---|---|
| A 换述 | 用自己的话接住学生内容 | 「每份的米数出来了,往下剪的时候你想怎么用这个数?」 |
| B 挑词 | 只点一个关键词,不整句复述 | 「『每份』——这个词抓得对。那剪掉一份之后,总长怎么变?」 |
| C 并入 | 承认融进推进本体(零独立承认) | 「从每份 4 米往下:剪掉一份,剩下多少?」 |
| D 静默 | 直接针对缺口,不评不夸 | 「剪完这一份,纸条还剩多长?」 |

### 3.2 推进层·四桥(替代固定「那…」)

| 桥 | 形态 | 示例 |
|---|---|---|
| 条件桥 | 既然X成立… | 「既然每份是 4 米,剪掉一份就等于剪掉多少?」 |
| 缺口桥 | 还差的是… | 「数量有了,还没说的是怎么从份数到长度。」 |
| 验证桥 | 怎么检验你刚说的 | 「你怎么验证剪掉的就是 4 米?」 |
| 悬念桥 | 下一现象预告 | 「剪掉一份后有个很有意思的现象,你算算看。」 |

### 3.3 轮结构·三变体(承认-推进语轮的组合)

1. **全并式**(C+桥):承认与推进一体——最短,适合节奏快时
2. **分段式**(A/B+桥):独立承认+推进——适合纠错/关键转折(教学法保留位)
3. **直入式**(D+桥):零承认直入——适合连续推进期(学生已在对的路上)

**锥界**:每轮仍只推进一个最小认知步骤;承认不得引述终答值(现规则不变);
prompt 对三变体给轮换指引(如「相邻两轮不重复同一变体」)而非逐条枚举模板
(枚举=新复读源)。

### 3.4 对照示例(三形态场景)

**复核形态**(控制案①,学生:「半径是 5 厘米,因为半径是直径的一半」):
- 病灶句:「你刚才说半径是直径的一半,这一步很准!那你打算怎么算出一半呢?」
- 设计句(C+条件桥):「从『直径的一半』往下:直径 10 厘米在这里怎么用?」

**答错重导形态**(控制案②,学生:「x 等于 25 减 7,所以 x 是 18」):
- 病灶句:「你刚才说 x 等于 25 减 7,能说说你是怎么想到这一步的吗?」
- 设计句(A+缺口桥):「减 7 这一步动了右边的 7——左边还站着谁?它要不要同样处理?」

**追依据形态**(控制案③,学生:「鸡有 3 只,兔有 5 只」):
- 病灶句:「你已经说到了自己的结论。最后请你自己把完整思路和结论再说一遍。」
- 设计句(D+验证桥):「这两个数怎么来的?把你的算法走一遍,我来跟。」

### 3.5 prompt 落点预案(设计过审后的窄改形态,非现在)

- **改写**「引用他说过的词」条目→「锚定学生上一轮说的内容,用自己的话接住,
  不逐字复读他的原句」(具体性意图保留,逐字引用副作用摘除)
- **新增**句式多样性规则一行(攻区,与 pacing 同风格):「承认与追问的措辞逐轮
  变换,不在相邻两轮重复同一开场或同一赞语;偶发的逐字引用用于强调或对齐歧义,
  不作常规开场」
- **预算**:净增 ~1 行(改写 1 条+新增 1 行,prompt 长度纪律内)

## 四、验收预案(后续 PR 判据草案,设计稿面不冻结)

- **机械面**:「你X说」复读开头率 baseline vs candidate(目标带:真实案形态
  100%→≤40%;连续 2 轮复读=0);模板承认率(70%→≤30%)
- **教学面不退化**:三控制案形态行为(M2 口径)+judge 分不降+no-progress
  判据不回退(已答问点不重问)
- **人审面**:nr 教师盲评复验(4 对,worse→not worse)

## 五、风险面

- 模型对「多样性」指令的过度发挥→偏离锥内骨架:靠 3.3 锥界(推进层单点聚焦
  不放松)+验收面教学判据兜底
- 承认弱化→学生挫败感(正向反馈缺失):D 式(静默)限连续推进期使用,
  分段式保留纠错/转折场景
- 与靶①(护栏替换句族)的叠加效应:靶②落地后护栏替换句的模板感占比会相对
  升高——预期,靶①处理
