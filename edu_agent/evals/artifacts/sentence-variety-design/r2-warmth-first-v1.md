## 二、暖度主线(不变;锥内;开场位不动)

### 2.1 承认位:从「弃」改「变」(温度分级轮换)

- **A 换述式**(温):用自己的话接住学生说的内容——主力
- **B 挑词式**(温):点出学生抓对的关键词——主力
- **C 并入式**(中):把学生的结论并进下一问——节奏快时
- **D 静默式**(冷):**限用**——仅学生连续答对的推进期,相邻轮不连用;关键步/纠错转折必须回 A/B

暖度读数目标带:承认率(含变式)30%~60%;赞语**换着说**,不回「这一步很准!」模板族。

### 2.2 收束/复核形态

- **固化 R1 赢面**:方法层复述+赞语收尾(对 4 模型侧路径)。
- **kernel 步进级背板文本**(对 2「我们从这里入手:」族)= 两臂共有,不进臂间对比(沿 R1 口径)。
- **收束复述要求(呈 PM 二选,§5 落点联动)**:现行 main TACTICS 已有「需要收束确认时,
  请学生自己完整说一遍结论」(338114f,#310 VERDICT#6);但 R1 candidate 末轮实测
  **未触发**该行(直接进总结)——冻结稿提案本意=把复述要求固化为标准收束路径。
  - **R2a(零新增,推荐)**:靠既有行+承认位暖度行间接带动(R1 对 4 赢面=模型侧
    方法层复述,无新规则也发生);最小 diff。
  - **R2b(+1 行,冻结稿提案原文)**:「总结前最后一轮,先请学生自己完整说一遍
    结论,确认后再进入总结」——显式固化收束路径。
  - 两案都是锥内「学生自述」触发器,不替代学生自述;判停判据(听者能理解)不变。

## 三、Thin Kernel 现实对齐(本稿新增核心;架构师裁定 §10-11 采纳记录)

**B 类审判终局=thin 语义:tone/format 原文直通,prompt 独占语气面**——R2 的分量比
原计划重:_TONE_DIRECTIVE 从「配合 kernel 语气护栏」变为**唯一语气防线**。

### 3.1 prompt 独占教学面清单(逐面映射 main@cacbe9c 现状)

| 面 | 现状(owner 已是 prompt) | prompt 职责边界 |
|---|---|---|
| grounding | TACTICS 守段(首问只确认范围/不判答案/年级词汇) | 已有,R2 不动 |
| 重问(anti-reask) | #361 行(TACTICS:「视为已完成问点…」)+复合体兜底(repeat regen,kernel) | **正向引导已有行**;机制重复=不做(复合体管复读,prompt 不写「禁止复读」机制句) |
| 过度收集 | 判停判据行(「学生只报最终答案而无思路…不算自己讲出」) | 已有,R2 不动 |
| 答在题里 | 转述式确认行(「不引述他结论里的最终答案数字」);泄露归 kernel(A 类掩码/block) | prompt=事前引导(不引终答数字);kernel=事后确定性恢复(掩码/block)。**层间不重复,互不越界** |
| no-progress | #361 行+复合体在 | 已有,R2 不动 |
| restatement(复讲) | elicit×3 已删;TACTICS 收束行(请学生完整说结论)+feeds-repair 终文(kernel,SAFE_FALLBACK_TEXT) | prompt 面承接「触发学生自述」(已有行);确定性 elicit 句族不复活 |
| **tone** | tone guard 直通(kernel 不拦不改);_TONE_DIRECTIVE 独占 | **R2 主战场**(§2.1+§5) |

**Kernel 存在原则(裁定 §11)落地口径**:亲切/自然/推进默认 owner=Prompt/Model;kernel
只保留四条件全满足者(模型反复稳定失败+真实 failure family+确定性机制稳定解决+副作用低)
——现行残留=复合体(repeat regen+reveal 兜底+stuck)+A 类掩码/block,均满足;R2
不再向 kernel 添加任何语气/暖度机制。

### 3.2 两臂共有 kernel 文本清单(v2 盲评意识面,不进臂间对比)

`SAFE_FALLBACK_TEXT`(feeds-repair 终文)、`NEEDS_REVIEW_TEXT`(梯尽终文)、
`PURE_BLOCK`(泄露纯 block)、reveal 引导语(`_STEP_LEADS`/「我们从这里入手:」族)、
stuck 支持句(`_SUPPORT_HINT`)。两臂同 kernel(thin)同文本——**配对差异只可能来自
prompt**,这恰是「prompt 面唯一变量」的实验保证。

### 3.3 R1 归因对象的消解(bottomout 句族已入土)

R1 对 1 部分冷感与 M2 ①案 judge 4→1 的机制性解释含「这一步我们直接看结果」双
bottom-out 句族——**该句族已随 Thin Kernel 删除**(梯尽=NEEDS_REVIEW_TEXT)。v2 重放
世界与 R1 世界不同:①案双 bottom-out 失败模式不复存在;**R1 全部数值仅作历史锚,
不与 v2 读数直接比**(判读线对 v2 世界重新冻结,§6)。

## 四、Minimum Sufficient Teaching Evidence 契约(成稿方向;架构师指定的未来 prompt 契约)

**方向**:判停/总结的判据从清单式(「关键步骤+关键依据+结论」三件全)收敛为**最小充分
教学证据**——学生表达中足以让听者复现解法的最小证据集;「最小」压过度收集,「充分」
压过早判停,与现行判停判据行(听者能理解)同向但更可操作。

**R2 立场(范围纪律)**:v2 **不改判停语义**(M3 判读线依赖现行判据跑通);契约成稿
(措辞、验收形态、与输出契约 ready_to_confirm 的对齐)归 **Prompt VNext 主线**,
R2 设计只入方向锚——本节即锚,不产生 v2 diff 行。
