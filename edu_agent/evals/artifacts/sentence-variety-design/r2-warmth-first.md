# 靶② R2 设计稿 · 暖度优先改版(PM 裁决框架;R1 负结果教训驱动)

**R1 教训一句话**:弃赞语=弃暖度——用户读的是**亲切感**,不是分布指标。
R1 机械面「模板承认 100%→0%」被判读为改善,但真实长案(对1)零赞语=冷感,
用户盲判 worse 击穿。R2 承认位从「弃」改「**变**」。

## 二、R2 设计(锥内;开场位不动——结构代价等靶①)

### 2.1 承认位:从「弃」改「变」(轮换+保温)

R1 四式保留,**温度分级**:

- **A 换述式**(温):「每份的米数出来了,往下剪的时候你想怎么用这个数?」——主力
- **B 挑词式**(温):「『每份』——这个词抓得对。那剪掉一份之后,总长怎么变?」——主力
- **C 并入式**(中):「从每份 4 米往下:剪掉一份,剩下多少?」——节奏快时
- **D 静默式**(冷):**限用**——仅学生连续答对的推进期,且相邻轮不连用;
  学生答对关键步/纠错转折时必须回 A/B 式给温度

**暖度读数目标带**:承认率(含变式)30%~60%——R1 的 0% 过冷,基线 70% 过模板;
赞语**换着说**(B 式挑词天然多样),不回「这一步很准!」族。

### 2.2 收束/复核形态:R1 赢面与靶①边界(PM 审读修正)

- **① 模型侧复核指令式**(R1 真赢面,R2 固化):复核/重导时模型侧直接给认知支点
  +推进指令——R1 实证(candidate T2:「我们从这里入手:直径是半径的两倍。
  你接着算下一步。」)。R2 固化为此形态的优先选择。
- **② kernel 兜底句族(非赢面,移出 R2 赢面清单)**:「这一步我们直接看结果:X。
  你先记住它,我们回头再讲一遍为什么。」系模型轮被拦后的**两臂共有** kernel
  文本,不进臂间对比;用户盲审对该句明确批评(「为什么要直接看结果?学生前面
  已经答出来了」)。**R2 不背书该句族,其重设计归靶①裁定**(裁定请求
  c5728372739+附录;bottomout-sample-target1.md 为直接材料)。
- **③ 追依据→收束**(R1 赢面+设计提案):R1 实证赢面=candidate 末轮总结确认
  (「你用假设法把每一步都讲清楚了:……这思路完全正确!」)。
  **设计提案**(非 R1 原句,candidate 末轮无复述要求):收束加复述要求
  「你已经把每一步都讲清楚了。最后请你自己完整说一遍结论。」——与锥内
  「学生自述」步骤(总结判据=学生自己讲出)同向:复述要求是**触发**学生自述的
  收束路径,不替代学生自述本身;判停判据(听者能理解)不变。

### 2.3 开场位:不动(PM 令②)

R1 实测开场粘性(变体扩散 ≈90-100%)超出纯 prompt 效力——**等靶①**
(kernel 层开场轮换器,架构师裁定请求 c5728372739 附录已强化)。
R2 不再对开场位加码 prompt 规则(期望值低且挤温度预算)。

## 四、验收预案(跑前冻结另落;判读线)

- **暖度面(新)**:承认率(含变式)30%~60%;长案(≥8 轮)不得零赞语
- **机械面(降权)**:连续 2 轮复读=0 保留;开场率指标移靶①
- **教学面**:M2 三形态不退化+judge 不降(①案 bottom-out 归靶①,单案噪声注记)
- **人审面(硬线)**:盲评重跑,**对1 not worse**(R1 击穿位优先复验)
- 预算:同 R1 量级(~53 calls 硬顶 60)
