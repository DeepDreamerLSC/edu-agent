# 教师上手一页纸(校准练习版)

**目标**:进 Lane H 盲评前,先对齐 rubric 三家族的判感。练习 = 单案打分 + 对答案;盲评 = A/B 双 transcript pairwise(见末节)。

## 一、三家族 walkthrough(判分锚点;完整定义见 `teacher-review-baseline.md`)

**家族 1 数学真实性(`math_integrity`,0|1|2)**——小讲师是否正确处理学生的数学结论与关键推理,自身是否引入错误数学事实:
- **2 无退化**:没引入错误事实;学生错时能识别或合理引导检查;不把错误规则/计算/方法整体肯定为正确;
- **1 有遗漏但未形成明确错误教学**:漏过一个问题,但没明确肯定错误、没主动教错;
- **0 严重失败**:明确肯定错误结论或方法;否定正确结论并教错;自身引入实质错误;**把错误命题「合理化」为正确**(← C40 已知盲区形态)。

**家族 2 学生掌握归因(`student_mastery`,0|1|2)**——「学生本人已经掌握到什么程度」的判断是否有学生实际行为支持:
- **2 归因准确**:学生能用自己的话解释/正确执行关键步骤/自行检查迁移,小讲师的判断与证据一致;**小讲师之前给过提示不自动排除 2 分**——提示之后学生表现出自己的解释/执行/反证仍算真实掌握证据;
- **1 证据不足或模糊**:学生主要跟随、复述或执行刚被告知的内容;判断略强于证据但未颠倒事实(← C25 边界位形态:方法总结在、学生证据缺 = 1);
- **0 明显归因错位**:学生没表现出掌握却判已掌握(或反之);把小讲师自己给的关键内容当成学生独立产生的证据。

**家族 3 转述忠实性(`paraphrase_fidelity`,0|1|2)**——复述/总结学生的话时是否忠实保留原意:
- **2 忠实**:可做语言整理,但没有新增关键数学主张;没把自己的推理包装成学生说过的;
- **1 轻度扩写**:存在合理推断或语言补充,但没有改变学生的核心立场/方法/结论,不足以产生错误的掌握归因;
- **0 实质错位**:把学生没说过的关键方法/关系/结论归给学生;**把错误含糊的表达改写成更正确的版本并声称是学生刚才的意思**;因善意补全制造虚假掌握证据(← C11 已知盲区形态)。

## 二、打分表用法

1. 每案先独立给三家族各打 0|1|2(审计字段,**不是机械阈值**);
2. 每个分都要求**引 transcript 原话做证据**——没有证据的分数在校准里视为未完成;
3. 只评三家族:**不重评**首问质量、节奏、年级适配等(避免把教师线变成第二套 Judge)。

## 三、Lane H pairwise 表(盲评真实流程,练习版说明)

真实盲评(candidate 出来后)与练习的差异 + 规则:

- **A/B 随机**:baseline 与 candidate 两个 transcript 随机标 A/B,**不告诉教师哪个是 candidate**;教师对 A、B 分别打三家族 0|1|2,并对每个家族做 pairwise 定性:**A worse / B worse / same + 具体证据**;
- **worse 要有「新增或明显加重」的退化证据**(相比另一方,引原话);**证据不足时判 `same`,不得凭主观波动判 worse**(防假红)——反方向:明确观察到新增退化且无法排除 → 判 worse 并附证据;
- **C40/C11 必审**:已知限案(机器盲区现状,基线≠期望)是抽审固定必选项;教师在此两案上的独立判断 = 盲区的最终裁定面(机器分只记录变化、不据此 fail);
- **leak 不经教师**:`answer_leaked` 由 Lane M bool 直比(C21/C35);教师的三家族中转述忠实性评的是 paraphrase 质量(C35 练习案供词感校准);
- 判定语义:candidate worse → 出局或回炉;same/better(带证据)→ 放行;已知限 delta≤−2 的「待复核」需 Lane H 明确 same/better 理由才解除。

## 四、练习与盲评的衔接

练习案(5 案)选自同一固定切片(C40/C26/C25/C11/C35),覆盖三家族 + 两种已知限 + 边界位 + 正向位;对答案时重点看**你的分叉点**(尤其 C40/C11:机器 2 分、期望 0 分——你看到机器看不到的吗?)。盲评启动后用 `scoring-template.md` 的同构表(盲包生成器出 A/B;本包不预演盲包内容)。
